# Buenos Aires Real Estate Analytics Dashboard

## Project Overview

This project analyzes apartment prices in Buenos Aires using Python and Power BI.

The project explores how apartment prices are influenced by:

* Apartment size
* Neighborhood
* Geographic location

## Tools Used

* Python
* Pandas
* Seaborn
* Jupyter Notebook
* Power BI

## Project Workflow

1. Data cleaning and preprocessing using Python
2. Exploratory Data Analysis (EDA)
3. Apartment price analysis
4. Interactive dashboard creation in Power BI

## Key Insights

* Larger apartments generally have higher prices
* Some neighborhoods show significantly higher average prices
* Geographic location strongly affects apartment pricing

## Dashboard Features

* KPI cards
* Scatter plot analysis
* Neighborhood comparison
* Price distribution
* Interactive filters and slicers
* Apartment location mapping
